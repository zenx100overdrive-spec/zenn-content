## 背景：仕様書を書いて運ぶ係になっていた

AIに仕事を任せるたびに、私は「一次仕様書」を書いて各AIへ渡していました。そのときの自分の言葉をそのまま引くと、

> 俺が全部一人で、一次仕様書みたいなのを各AIに渡していく作業がかなり生まれてるんだよ。これ非効率なんだよね。これ多分俺倒れちゃうね。

8月末〜9月中旬のChatGPTとの会話を数えると、まとまった相談49回のうち34回で、AIに「依頼書」を書かせていました。ある AI の出力を別の AI に貼り付けた回数は、約150回です（どちらも会話ログを機械的に数えた値）。

## つくったもの：声が、そのままエージェントに届く

やったことは小さいです。

1. ChatGPT/Codex アプリで音声入力すると、書き起こしがPCのローカルに残ります。
2. その書き起こしを、自分用のローカルの記録（SE）に「本人が話した言葉」として取り込みます。
3. Claude Code は、新しい書き起こしが現れるまで待機していて、現れたら起きて読みます。

```python
# 新しい書き起こしが出るまで待つ（本文は出力しない）
while time.time() < end:
    new = {k: v for k, v in completed().items() if k not in seen}
    if new:
        print(json.dumps({"event": "NEW_VOICE", "count": len(new)}))
        break
    time.sleep(20)
```

送信ボタンも、整形も、貼り付けもいりません。

## 結果：約1時間で音声17回、貼り付け0回

10月1日の14:03〜15:13に、私は音声で17回話しただけでした。Claude Code へのキーボード入力・貼り付けは0回です。その間に Claude が進めたのは次の作業です。

- 話した事業の考えを、私の言葉だけで企画メモに構造化
- 過去の市場分析の集約（売上の記録0件、などの「抜け」も含めて）
- 思いついた案の規約チェック（自動投稿が規約違反だと条文で確認）
- note と Zenn の市場調査（ハッシュタグとトピックの記事数）

途中で私がこぼした感想です（書き起こしの誤変換だけ直しています）。

> 俺が音声入力した時点でクロードが勝手に参照してくれてるから、もう市場調査が始まってるんだよ。俺はすごく助かってるよ。

## 「それ規約違反です」

途中で私は、こう話しました。

> 放置してても金が稼げるというか、仕組みを作りたい。で、まあアイディアとしては楽天ポイントとかポイント系、（中略）AIが自動的に、えっと、アフィリエイトっていうかな。（中略）こっちに関しては俺はあんまり介入したくないなと思ってて。

数分後、Claude Code は楽天ROOMの利用規約の原文を取りに行き、こう返してきました。

> 楽天ROOM 利用規約 第11条第1項第4号：「スクリプトその他のプログラムを実行する等の方法により、機械的に投稿、コメント等をする行為」は禁止。
> → 投稿まで自動化する形は規約違反。この形では進めない。

止めたうえで、規約の範囲の選択肢（AIが候補と文を用意し、人は選んで手で投稿する／自分のサイトに置く）を並べてきました。私はそれを見て、自分のサイトは「マーケティングがマーケティングを呼ぶ」状態になるから合わない、と話しただけで、その条件も次の調査に反映されました。

## それでも、人に残ったこと

全部が自動になったわけではありません。この日、私のところに戻ってきたのは次の4つだけでした。

1. **公開するかどうか**。Claude Code は記事の下書きまで作り、「公開は人の判断」として止まりました。私は「公開してよし」と返しただけです。
2. **ログインが要る操作**。Zenn のアカウント連携と GitHub のリポジトリ作成は、私の認証が必要なので、手でやりました。数分です。
3. **事実の確認**。タイトル案に「寝ながら」とありましたが、記録に残っていたのは「寝ながら動画を見ていた」ことだけでした。Claude Code は「しゃべった時も寝転んでいたなら使える」と確認を返してきて、私が「基本俺は椅子座席倒してゆっくりしてる」と答えて決まりました。
4. **どこまで消すか**。古い記事の扱いは「削除処理はgithubの方だけで大丈夫」の一言で決まりました。

逆に、途中で見つかった問題は、私が気づく前に Claude Code 側で直っていました。

- 音声入力アプリの履歴は**新しい20件しか残らない**ことが分かり、この日の午後の書き起こし5件が、すでにPCから消えていました。
- Claude Code は自分の作業ログから本文を取り戻し、以後は**2分ごとにすべての書き起こしをローカルの記録へ保存する**ようにしました。
- 記事の数字も、公開前の見直しで「音声11回」が誤りで、正しくは17回だったと直されています。

人に残ったのは、**決めること**と、**本人にしかできない認証**だけでした。運ぶこと・整えること・調べること・直すことは、残りませんでした。

## 仕組みの全体（ざっくり）

| 役割 | 何が | 頻度 |
|---|---|---|
| 話す | 私（音声入力） | 思いついたとき |
| 書き起こしを保存 | ローカルのスクリプト | 2分ごと |
| 起きて読む | Claude Code（新しい書き起こしを待機） | 話した直後 |
| 調べる・まとめる・直す | Claude Code（必要なら別のAIに検証を依頼） | その場で |
| 人に返す | 「判断待ち」1ページ（お金・規約・公開・ログインだけ） | 必要なときだけ |

## わかったこと

> AI / System側がHumanの活動を観測し、「これはHumanにやらせる必要がない」と判断できる仕事を見つけ、Humanから取り除いていく方が適しているのではないか。

## 限界

- 書き起こしには、AIに向けていない独り言や、個人的な話も入ります。ローカルから外に出さない、Claude宛てと分かるもの以外は命令として扱わない、と決めています。
- アプリでの会話の本文はPCに残らないので、拾えるのは音声の書き起こしだけです。
